# Winter 2026 Assignment Tracker

A beautiful assignment tracker for UCSB Winter 2026 courses:
- **SOC 173** - Sociology of Law
- **SOC 130** - Sociology of Revolutions  
- **ANTH 5** - Biological Anthropology

## Features
- ✅ Track assignment completion
- 📊 Progress bars and grading breakdowns
- 🔔 24-hour deadline alerts
- 📦 Manual archive control
- 💾 Data persists in browser storage

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g., `assignment-tracker`)
2. Upload `index.html` to the repository
3. Go to **Settings** → **Pages**
4. Under "Source", select **Deploy from a branch**
5. Choose `main` branch and `/ (root)` folder
6. Click **Save**
7. Wait 1-2 minutes, then visit: `https://YOUR-USERNAME.github.io/assignment-tracker`

## Why GitHub Pages?
iPad Safari blocks external scripts (React, Tailwind) when opening local HTML files. 
GitHub Pages serves over HTTPS, which allows all scripts to load properly.
